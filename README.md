# TVM-EV-Financing-Analysis
A finance project demonstrating the real-world application of Time Value of Money (TVM) concepts in Electric Vehicle financing, including EMI calculation, loan structure analysis, foreclosure evaluation, and repayment decision-making using Tata EV case studies.
# TVM EV Financing Analysis

## Overview
This project demonstrates the practical application of Time Value of Money (TVM) concepts in Electric Vehicle financing using real dealership data collected from Tata Motors.

## Key Concepts Covered
- EMI Calculation
- Loan Structure Analysis
- Foreclosure Analysis
- Reducing Balance Method
- Financial Decision-Making

## Case Studies
- Tata Tiago EV
- Tata Harrier EV

## Tools Used
- Microsoft Excel
- Financial Formulas
- Loan Amortization Concepts

## Learning Outcomes
- Understanding real-world loan financing
- Applying TVM formulas practically
- Comparing repayment strategies
- Evaluating foreclosure benefits
